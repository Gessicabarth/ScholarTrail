# Scholar Trail

<br>

## Sobre o Projeto
O Scholar Trail é um jogo de tabuleiro educativo em 2D que desenvolvi em Python utilizando a biblioteca Pygame. Criei este projeto como um trabalho para a disciplina de Linguagem de Programação Aplicada do meu curso de Ciência da Computação. O meu objetivo principal com o jogo é unir diversão e aprendizado, permitindo que os jogadores testem e fixem os assuntos do curso respondendo a perguntas para avançar no tabuleiro.

## Motivação
A ideia deste projeto nasceu das minhas lembranças e da nostalgia dos jogos de tabuleiro clássicos, além dos momentos com meus amigos na frente do computador. O meu objetivo foi trazer de volta essa dinâmica de jogar em grupo, transformando-a em uma ferramenta de estudo. A intenção é criar um ambiente onde a revisão dos conceitos de Ciência da Computação aconteça de forma divertida e leve. Este repositório apresenta a versão beta do meu projeto, que continuo aprimorando para o lançamento de uma versão 2.0.

## Funcionalidades e Decisões de Design
* **Modos de Jogo:** Adicionei suporte para partidas de 1 ou 2 jogadores ao mesmo tempo.
* **Mecânica de Quiz:** Configurei o avanço das peças no tabuleiro para depender do acerto de perguntas sobre os conteúdos de Ciência da Computação.
* **Usabilidade e Conforto Visual:** Pensei no design inteiramente voltado para a usabilidade do jogador. Criei o plano de fundo para transmitir um aspecto divertido, inspirado inicialmente na identidade visual do meu portfólio. Projetei a estrutura estética já prevendo uma futura implementação de alternância entre temas (light mode e dark mode), evitando desde o início o uso de fundos brancos fixos que possam causar desconforto visual.
* **Personagens:** Foram inspirados em mim e no meu marido.

## Tecnologias Utilizadas
* **Linguagem:** Python
* **Biblioteca:** Pygame
